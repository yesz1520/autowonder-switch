# autowonder-switch

English | [中文](README.md)

autowonder-switch lets multiple AutoWonder executor identities share your local Codex or Claude Code installation. Start the daemon from the repository root and open `http://127.0.0.1:8787` to add and manage connections.

```sh
go run ./cmd/autowonder-switch
```
