# autowonder-switch

[English](README.en.md) | 中文

autowonder-switch 让多个 AutoWonder 执行器身份共用本机的 Codex、Claude Code 或 pi。在仓库根目录启动 daemon，打开 `http://127.0.0.1:8787` 添加和管理连接。

```sh
go run ./cmd/autowonder-switch
```
